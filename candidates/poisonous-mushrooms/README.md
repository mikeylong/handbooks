# Poisonous Mushrooms Handbook

This private repository owns the handbook’s working source and preserved draft artifacts. The handbook is not approved for publication and is not in the public gallery.

Generation A and B are two retained candidates under `generation-a/` and `generation-b/`. Each has its own source, evidence, images and PDF. Building needs Python, Chromium and the separately cloned publishing toolkit; set `HANDBOOK_PUBLISHING_TOOLKIT` to its local directory. The toolkit fixtures remain in their original repository.
