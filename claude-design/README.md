# Claude Design Field Guide

Extend a product from its existing design system, prove the result, and carry it into code and Figma. Version 1.2.1, published October 5, 2026, follows Velori through one Review configuration extension. It includes a runnable React sample, a machine-readable Markdown edition, and matching 56-page Daytime and Late night PDFs.

[Read online](https://handbooks.surfaces.systems/claude-design/) · [Edition and downloads](https://handbooks.surfaces.systems/claude-design/editions/v1.2.1/) · [Read the manuscript](./Claude_Design_Field_Guide_Source.md)

Use the Daytime version for printing and the Late night version for dark reading. Both contain the same content, links, page labels and final-page changelog, compared with the preserved version 1.2.0.

Start with [the Velori sample](./samples/velori-store/README.md). Its walkthrough gives the inputs, terminal commands, browser journey, expected results and reset instructions. The package includes product sources, asset and token manifests, import rules, source-conflict records, thirteen prompts and validation scripts. Download the MIT React sample and native Figma companion from the edition page. Import the `.fig` into your own Drafts; access to the author’s file is not required. The variable-driven Figma journey requires a paid Figma Design or eligible Education plan with edit access. Captured Claude Design packets and runtime records are excluded.

Version 1.2.0 was checked in a new private Claude Design system: imported-system fidelity, a correction followed by a second generation, a fresh Review configuration, and an authentic Code handoff. Complete native archive bytes were preserved before an offline host adapter was validated. The bounded React adaptation and native Figma correspondence were checked separately. Version 1.2.1 adds a complete native `.fig` export, verified through a fresh Drafts import, local dependency checks and one nondefault prototype journey. Figma uses substituted fonts and prototype navigation; its simulated unavailable state does not prove real image failure or browser reload persistence. Full pixel parity, organization-wide access policy, production APIs and assistive-technology acceptance are not claimed.

Follow [the build instructions](./Claude_Design_Field_Guide_README.md) to reproduce the PDFs and reader. The reader and PDF layout use the shared publishing toolkit. Extract that toolkit beside this book and set `HANDBOOK_PUBLISHING_TOOLKIT` to its directory when working outside the collection.

Data Pipeline Studio, its [local coding exercise](./Local_Coding_Exercise.md), and the earlier Simple Design System materials remain historical examples. Earlier PDFs, public download routes, artwork and review records are preserved. The version 1.2.0 source and release metadata are retained in [baselines/v1.2.0](./baselines/v1.2.0/); earlier metadata and binding records remain in [baselines/v1.1.0](./baselines/v1.1.0/).
