# Claude Design Field Guide

Explore, refine and hand off an interactive product design. Version 2.0.0, dated October 6, 2026, includes nine chapters, a guided Velori exercise, a Markdown edition and matching 53-page Daytime and Late night PDFs.

[Read online](https://handbooks.surfaces.systems/claude-design/) · [Edition and downloads](https://handbooks.surfaces.systems/claude-design/editions/v2.0.0/) · [Manuscript](./Claude_Design_Field_Guide_Source.md)

Start with Figma foundations and screens or an existing component library. In Claude Design, brief the task, compare directions, choose, refine, connect the journey and review it with people. Finish with a reviewed prototype and usable handoff. Continue into Claude Code or Figma when the next owner needs that deliverable.

Download the Velori exercise and native Figma starter from the edition page. Unzip the exercise, read its README and import the starter into your own Drafts. Use your own accounts and source copies. Access to the author's private Claude Design system or Figma file is not required. The archive includes the brief, prompt sequence, walkthrough, decision record, handoff template, offline prototype and static editable Figma continuation. Keep the completed answer key out of initial generation context.

The author trial checked system import, three alternatives, chat and comment corrections, retained choices, keyboard navigation, narrow layouts and a local-agent handoff. Direct editing reverted on Save; the guide records the chat fallback. A fresh same-account Figma import retained instances, text styles and variables. The continuation has no prototype reactions or state wiring. Human task review, another recipient account, Code implementation and recovery from a real missing resource remain untested.

The PDFs preserve their exact approved bytes. Earlier editions, sample downloads, artwork and review evidence remain available. The source and release metadata for 1.3.0 are retained in [baselines/v1.3.0](../v1.3.0/). The old React engineering exercise remains in [samples/velori-store](../../samples/velori-store/) as supporting material.

The book uses thin build adapters and the shared publishing toolkit. Set `HANDBOOK_PUBLISHING_TOOLKIT` when extracting the toolkit outside the collection. The [PDF configuration](./pdf-config.json) records the manuscript and layout; [release evidence](../../qa/v2.0.0/) records exact comparisons, artifact validation, visual review and publication approval.
