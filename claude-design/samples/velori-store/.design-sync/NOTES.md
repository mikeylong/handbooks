## Re-sync risks

- Asset-only changes move the deterministic guideline inventory and native auxiliary hash, while component source keys stay stable. Native upload.any detects them but automatic grade carry-forward does not. Any inventory change requires fresh ProductPreview and AccessoryPhoto captures and visual grades.
- Wrapper changes alter the native grade contract; all scoped previews need a fresh full pass. Do not grade unread sheets or use earlier placeholder captures as fidelity proof.
- Classic-script project-relative loading is locally verified. Inline/module loading keeps the root fallback; actual native hosting, font correspondence, card behavior, generation and executable handoff still need separate evidence.
- Converter dependencies and the installed implementation vary by tool version. Preserve current script/dependency fingerprints, recheck the delegate export contract and staged MIME repair, and rebuild through the DRIVER after source/header changes.
