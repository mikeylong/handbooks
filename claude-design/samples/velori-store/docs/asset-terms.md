# Velori sample terms

Michael Long created Velori as a fictional company and design system. The Velori sample source, documentation, frozen consumer reference, product imagery, expression masks, robot layers, and generated-image prompts are available under the [MIT license](../LICENSE). You may use, modify, and redistribute these materials with the copyright and license notice.

The separately downloadable [native Figma companion](https://handbooks.surfaces.systems/claude-design/editions/v1.2.1/velori-design-system-configurator.fig) contains Michael Long’s authored Velori design-system definitions, layouts, prototype wiring and imagery. Those owned materials use the same MIT license. Keep the complete MIT and Lucide notices supplied in the [companion manifest](https://handbooks.surfaces.systems/claude-design/editions/v1.2.1/figma-companion.json) when redistributing the file. The native `.fig` is separate from this React ZIP.

The native file references Arimo Regular/Bold and Lora Regular. Font software keeps its own license; the companion archive contains no separate font binaries. Current [Arimo](https://github.com/google/fonts/blob/main/ofl/arimo/OFL.txt) and [Lora](https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt) releases use the SIL Open Font License 1.1. Check the actual font release’s terms if you distribute font software. These font references do not license font software under MIT.

Third-party software keeps its own license. Preserve the [Lucide notice](LUCIDE-LICENSE) for the icon definitions and the [React notice](REACT-LICENSE) for React. Installed dependencies include their notices; the lockfile records their exact versions.

The historical Claude Design export contains an Anthropic runtime (`support.js`) whose redistribution terms have not been established. That captured packet stays in the private review archive and is excluded from the public sample. The React app and its review screen run without that runtime. Follow the walkthrough to capture and validate your own native handoff.

[Image provenance](image-provenance.md) preserves the historical source record, including its original paths, commands and accessory variants beyond the single-accessory baseline. For the current package, use the [asset manifest](../public/assets/velori/manifest.json), [generated-image prompts](generated-image-prompts.json), and [README validation](../README.md#validate-an-extracted-copy). Record new image generation or alterations separately.
