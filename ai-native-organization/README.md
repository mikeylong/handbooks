# AI-Native Organization Handbook

Version 1.0.0 · October 23, 2026 · 41 pages.

Read the [official handbook](https://handbooks.surfaces.systems/ai-native-organization/) or its [edition page](https://handbooks.surfaces.systems/ai-native-organization/editions/v1.0.0/). The reader offers Daytime, Late night and Markdown downloads. Chapter 3 is an illustrative investment comparison; its numbers and results are synthetic.

From the collection root, run `npm --prefix ai-native-organization run validate` to check the frozen release. `npm run build` assembles the public gallery from approved packages and does not rebuild PDFs. Python, Node 22 and Poppler are needed for the complete release validation.

The editable manuscript is `source/build_handbook.py`. Reusable formatting lives in `../publish-evidence-backed-handbook/`. Prepare future editions in isolated candidate folders; preserve these released files and URLs.
