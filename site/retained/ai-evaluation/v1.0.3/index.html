Version 1.0.3 · 2026-11-09

Evidence-backed clarifications for AI Evaluation Field Guide.

Compared with 1.0.2.

  1. Addition · Agent and tool evaluation

    Agent and tool evaluation

    Add teamwork tests for missing context, unsafe pressure and inherited mistakes. Assess collaboration separately from isolated task success.

    Individual task scores do not establish reliable teamwork.

    Sources: arXiv author manuscript: Measuring AI Agents as Teammates with Collaborative Intelligence

  2. Addition · Monitoring and incidents

    Monitoring and incidents

    Separate monitoring coverage, review latency and escalation; record unreviewed activity and check missed failures independently.

    A low escalation rate does not establish effective detection.

    Sources: Anthropic Institute: Measurements for understanding the pace of AI development inside frontier labs

  3. Addition · Offline evaluation and production monitoring

    Offline evaluation and production monitoring

    Compare safety evaluations with matched production decisions using pre-decision sampling and aligned graders; test objective framing and report imperfect matching.

    Evaluation scores can differ from production safety in either direction.

    Sources: OpenAI Alignment Research: Eval-production behavior gaps in agent safety and the role of eval-awareness
