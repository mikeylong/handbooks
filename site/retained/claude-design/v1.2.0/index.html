Changelog

Version 1.2.0 · 2026-10-05

A source-grounded Velori exercise with explicit state preservation and a complete native handoff.

Compared with 1.1.0.

  1. Deprecation or removal · Orientation, capstone and product appendices

    Velori throughout the guide

    Replaced the Data Pipeline Studio assignment and Simple Design System reference with Velori: a preserved configurator, one Review configuration extension, and a portable React sample.

    One supplied product now carries the source, state, implementation and native Figma checks through the capstone.

    Sources: Surfaces: Velori MIT sample

  2. Addition · Chapters 2–3

    Source and fidelity checks

    Added source definition and conflict records, CSS and prop inventories, controlled import scope, asset hashes recorded before validation, fidelity checks of ten elements, and named correction fixtures followed by a second generation.

    Readers can resolve source disagreements and verify reuse before introducing the review screen.

    Sources: Anthropic: Set up your design system in Claude Design

  3. Correction or clarification · Chapters 4–7 and 10

    State and Figma contracts

    Specified retention of all four configuration values, keyboard and return focus, image recovery, narrow layouts, and native Figma component/variable correspondence. Detail photographs remain Chalk, and prototype visits are distinguished from browser reload persistence.

    These contracts expose state loss and unsupported claims of parity between tools.

    Sources: Figma: Velori Figma handoff

  4. Correction or clarification · Chapter 9

    Complete native Code handoff

    Corrected the local Code handoff to Copy prompt and authenticated source reads. Truncated binaries require a full native archive; captured bytes stay private and unchanged, host adaptations are disclosed, and each new packet is validated independently.

    Complete source and dependency bytes are required before executable handoff acceptance.

    Sources: Anthropic: Get started with Claude Design
