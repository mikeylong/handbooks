# First-publication change report

Version 1.0.0 is a new publication candidate. The comparison is against the unpublished August draft, 128 pages; the revised candidate is 138 pages. A previous approved public edition does not exist, so the edition changelog is not applicable and no changelog page or navigation entry is included.

The candidate keeps the twelve-chapter consulting sequence, twelve worksheets, fictional Harborline case, capstone, appendices, and mechanical engraving subjects. It strengthens the teaching examples and evidence boundaries, brings factual references to an October 1, 2026 cutoff, and packages the editable source with local fonts and frozen artwork.

The largest content change is the capstone. Cohorts, audits, candidate versions and denominators reconcile. Aggregate success cannot override the failed contract citation floor. The economics use monthly mean-based capacity assumptions, include ownership and cleanup, and show a negative expected case. The answer key funds a bounded repair only if the owners authorize it; expansion stays on Hold.

Other changes define qualitative opportunity ratings, demonstrate evidence/risk/decision records, add accessibility and responsible-AI diligence, clarify participation, define technical terms, and make handoff acceptance observable. Direct references distinguish inspected evidence from further reading.

The hosted reader is generated from the same 2,072 manuscript paragraphs, with no omitted body paragraph found. It includes the twelve retained plates and three occurrences of two authored diagrams. Readable diagram captions, semantic table headers, responsive callouts and URL wrapping support mobile reading. Shared appearance finishing, gallery return focus and search are reused across all three books.

`evidence/accepted-changes.json` records 64 accepted content, editorial and implementation changes with rationale. `evidence/builder-diff.patch` and `evidence/manuscript-diff.patch` preserve the exact source and extracted-text comparison separately. Site changes are visible in the detached worktree's Git diff. Neither the baseline nor the canonical Production and Evaluation artifacts was replaced.

The appearance selector was replaced after owner feedback. The shared menu passed 320/390/768/1280px layouts, all three choices, keyboard and focus behavior, saved preferences and adjacent navigation. See `qa/appearance/review.json` for the final control proof.
